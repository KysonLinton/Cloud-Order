# 约会 / 社交风格（Date & Social）

有吸引力，但松弛自然——让对方觉得你好看，又不会觉得你用力过猛。

## 风格定位

- 关键词：吸引力、亲近感、松弛、略有巧思
- 先看场合：咖啡厅约会 ≠ 高级餐厅 ≠ 户外活动，风格档位不同

## 核心单品

- 上装：针织开衫、合身衬衫、质感 T、V 领或方领上衣、小香风外套
- 下装：直筒牛仔、A 字中裙、西装裤、斜裁半裙
- 鞋：乐福鞋、小白鞋、玛丽珍、低跟靴（久走也不累）
- 配饰：一件有记忆点的饰品（耳环 / 手表 / 丝巾）、淡香、干净指甲

## 配色与材质

- 安全配色：米白 + 燕麦、酒红 + 黑、莫兰迪色系、奶油色 + 棕
- 柔和的暖调或低饱和更显亲近；纯黑全黑偏冷，可加一件暖色配饰
- 材质：柔软针织、真丝、羊毛——**触感好的面料更显温柔**

## 3 套万能公式

| 场景 | 公式 |
| --- | --- |
| 咖啡 / 逛街 | 针织开衫 + 素 T + 直筒牛仔 + 小白鞋 |
| 餐厅晚餐 | 合身衬衫 + 西装裤 + 乐福鞋（可加薄外套） |
| 户外活动 | 卫衣 + 休闲裤 + 复古跑鞋 + 棒球帽 |

## 场合适配

- 保证"坐着好看、站着也好看"，避免只适合摆拍的夸张单品。
- 有一点个人记忆点（颜色或配饰）比全身名牌更打动人。

## 避坑

- 不要为了显身材穿不透气的紧身衣，一整天不舒服会写在脸上。
- 香水宁淡勿浓，鼻尖半米能闻到就够。
- 鞋子一定要能久走，约会走两步就喊累很减分。
