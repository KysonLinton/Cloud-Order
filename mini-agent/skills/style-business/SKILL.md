# 商务 / 通勤风格（Business）

专业、可靠、利落——让人觉得你把工作当回事。

## 风格定位

- 关键词：专业、克制、利落、可信
- 两个档位：**商务正式**（西装领带/套裙）与 **商务休闲**（无领带，衬衫+西装裤）

## 核心单品

- 上装：衬衫（白/浅蓝/条纹）、针织 polo、薄高领、西装外套、结构感马甲
- 下装：西装裤、直筒西裙、深色直筒裤（避免运动裤、破洞、浅色牛仔）
- 鞋：牛津鞋、德比鞋、乐福鞋、尖头/方头低跟皮鞋（3-5cm）
- 外套：单排扣 blazer、风衣、羊毛大衣（冬季）
- 配饰：皮质通勤包、简约腕表、细皮带、金属小耳饰

## 配色与材质

- 安全配色：藏青 + 白 + 灰 / 黑 + 驼 + 白 / 炭灰 + 浅蓝
- 加深色西装时，衬衫留白，领口不堆叠
- 材质：精纺羊毛、棉质免烫衬衫、真皮；避免亮面化纤

## 3 套万能公式

| 场合 | 公式 |
| --- | --- |
| 商务正式（会议/客户） | 藏青西装外套 + 白衬衫 + 同色西装裤 + 德比鞋 |
| 商务休闲（日常通勤） | 针织 polo + 深灰直筒裤 + 乐福鞋 |
| 女式通勤 | 衬衫塞进高腰西裙 + 细皮带 + 低跟皮鞋 |

## 场合适配

- 见客户 / 面试 / 汇报：走正式档，颜色越少越稳。
- 普通办公日：商务休闲档，靠剪裁和面料撑住质感。

## 避坑

- 西装外套过紧会在腋下起皱，肩线要正好落在肩点。
- 别用运动鞋配正装西裤（除非是明确允许 smart casual 的公司）。
- 全身超过三种颜色，专业感会掉。
