# 文件总结

把用户指定的文件读完后，输出一份结构化总结。

## 步骤

1. 用 `read_file` 读取目标文件。文件较大时先用 `offset`/`limit` 分段读取，直到掌握全文结构。
2. 判断文件类型（代码 / 文档 / 配置 / 数据），据此调整总结重点：
   - **代码**：用途、入口、关键函数与数据流、对外依赖、明显的问题或 TODO。
   - **文档**：主题、核心结论、关键论据、待办事项。
   - **配置/数据**：结构、关键字段、取值含义。
3. 输出格式：

```
## 一句话概括
<不超过 40 字>

## 主要内容
- 要点 1
- 要点 2
- 要点 3

## 关键细节
<涉及的具体函数名、文件名、数值、日期等，标注所在行号>

## 需要注意
<风险、疑点、缺失信息；没有就写"无">
```

## 规则

- 只根据文件实际内容总结，不要引入外部猜测。
- 引用关键内容时标注行号，方便用户定位。
- 文件超过 3000 行时先告诉用户你打算分段处理，并说明会分几段。
