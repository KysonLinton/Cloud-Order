# 复古 / 学院风格（Vintage & Preppy）

有年代感的格调，规矩中带一点玩味。

## 风格定位

- 两个方向：**学院风 Preppy**（常春藤、英伦）与 **年代复古**（70s 波嬉 / 80s 复古运动 / 90s 街头怀旧）

## 核心单品

- 上装：牛津纺衬衫、麻花针织、polo、粗花呢外套、格纹西装
- 下装：卡其斜纹裤、百褶裙、灯芯绒裤、高腰阔腿牛仔
- 鞋：乐福鞋（配白袜）、布洛克皮鞋、复古跑鞋
- 配饰：领带/领结、针织马甲、贝雷帽、皮质邮差包、格纹围巾

## 配色与材质

- 学院配色：藏青 + 卡其 + 酒红 / 墨绿 + 米白 + 棕
- 复古配色：焦糖 + 燕麦 + 咖啡、橄榄绿 + 砖红
- 材质：粗花呢、灯芯绒、麻花针织、牛津纺、麂皮——**纹理感是关键**

## 3 套万能公式

| 风格 | 公式 |
| --- | --- |
| 学院 Preppy | 牛津衬衫 + 针织马甲 + 卡其裤 + 乐福鞋 + 白袜 |
| 英伦复古 | 格纹西装 + 高领针织 + 灯芯绒裤 + 布洛克鞋 |
| 70s 波嬉 | 麂皮外套 + 高腰阔腿牛仔 + 复古短靴 + 格纹围巾 |

## 场合适配

- 秋冬最能出彩，靠层叠和纹理堆出年代感。
- 约会、展览、咖啡探店、街拍都合适。

## 避坑

- 复古≠旧衣服，版型要利落，起球褪色会显邋遢。
- 格纹与条纹别同时大面积出现，容易眼花。
- 白袜配乐福是加分项，但袜筒别高过小腿肚。
