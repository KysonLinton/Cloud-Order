# 休闲风格（Casual）

轻松、舒适、不费力，但要有型——不是随便套一件睡衣出门。

## 风格定位

- 关键词：松弛、日常、亲和、不用力
- 目标：看起来"随便一穿就好看"，而不是刻意打扮

## 核心单品

- 上装：纯色圆领/亨利领 T 恤、宽松卫衣、法兰绒格纹衬衫、针织开衫、polo 衫
- 下装：直筒或宽松牛仔裤、休闲斜纹裤（chino）、工装裤、休闲短裤（长度在膝盖上下）
- 鞋：小白鞋、帆布鞋、复古跑鞋、乐福鞋（稍正式一点的场合）
- 外套：牛仔夹克、卫衣外套、轻薄工装夹克、棒球服
- 配饰：棒球帽、帆布托特包、简约腕表、细银链

## 配色与材质

- 安全配色：白 + 牛仔蓝 + 灰 / 米白 + 卡其 + 燕麦 / 黑 + 白 + 牛仔蓝
- 加分做法：全身中性色打底，用一件亮色单品（帽子、袜子、包）提神
- 材质：棉、针织、牛仔布、帆布；避免全身化纤反光

## 3 套万能公式

| 场合 | 公式 |
| --- | --- |
| 周末逛街 | 白 T + 直筒牛仔 + 小白鞋 + 帆布包 |
| 见朋友喝咖啡 | 针织开衫 + 纯色 T + 斜纹裤 + 乐福鞋 |
| 上课 / 通勤休闲 | 卫衣 + 工装裤 + 复古跑鞋 + 棒球帽 |

## 场合适配

- 无着装要求的日常场景基本通吃
- 需要"休闲但有格调"时，把 T 恤换成针织衫、把运动鞋换成乐福鞋即可。

## 避坑

- 不要全身都是宽松单品（上宽下宽会显臃肿），至少收一处。
- 破洞、大面积印花、夸张 logo 三选一，别全叠上。
- 短裤配长袜再配运动鞋，容易被认为"脱了鞋就上炕"，注意长度比例。
