# 极简风格（Minimal）

少即是多——靠剪裁、面料和比例取胜，不靠图案。

## 风格定位

- 关键词：干净、克制、高级、留白
- 全身颜色通常不超过 3 种，且以中性色为主

## 核心单品

- 上装：纯色 T、高领针织、无领衬衫、开衫、大衣
- 下装：直筒裤、阔腿裤、西装裤、直筒牛仔（无破洞）
- 鞋：小白鞋、乐福鞋、简约皮质德比鞋、切尔西靴
- 配饰：一只好表、素圈耳饰、极简皮质托特包

## 配色与材质

- 配色：黑 / 白 / 灰 / 米 / 藏青 / 驼——两两组合几乎不会错
- 材质是重点：羊绒、美丽诺羊毛、重磅棉、真丝；**好面料 = 极简的灵魂**
- 拒绝印花、大 logo、亮片、复杂装饰

## 3 套万能公式

| 场合 | 公式 |
| --- | --- |
| 日常 | 米白高领 + 直筒灰裤 + 小白鞋 |
| 稍正式 | 无领衬衫 + 西装裤 + 乐福鞋 |
| 秋冬 | 羊绒大衣 + 纯色高领 + 直筒裤 + 切尔西靴 |

## 场合适配

- 通勤、约会、日常、轻正式都能用，属于"低风险高质感"风格。
- 想加一点变化，靠材质对比（针织 × 皮革）而非颜色。

## 避坑

- 极简最怕"廉价感"：面料起球、版型松垮会立刻掉档。
- 颜色虽然少，但要控制冷暖调统一，别黑白灰里混一个荧光色。
- 剪裁要合身——极简没有印花帮你转移视线。
