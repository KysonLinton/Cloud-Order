# 用户档案流程

「档案」是穿搭管家给出建议的个人依据：性别、年龄、身高体重、体型、职业、常居城市、常去场合、风格与颜色偏好、禁忌、尺码、预算。
档案保存在本地 `.cloudorder/profile/profile.json`，**不会上传**；用户可随时修改。

## 工具

- `profile_get`：读取用户档案。推荐穿搭前先读一次。
- `profile_update`：更新档案字段（只传要改的字段）。**属于写操作，应先与用户确认再调用。**

## 步骤

1. **先读档案**：推荐搭配前调用 `profile_get`。
   - 若档案已有内容：把关键项（如"平时通勤为主、偏好简约、常穿黑白色"）融进建议，不必逐条念出来。
   - 若档案为空：用一两句话邀请用户填写，**不要一次问十几个问题**。可以挑最关键的几项（场合、风格偏好、常穿/不喜欢什么、尺码）聊出来。

2. **怎么收集**：优先在自然对话里了解（用户自己会提到场合、职业、喜好）。用户明确愿意让你代填、且确实说了某几项时，再用 `profile_update` 写入；**不确定的项一律不要填**。

3. **引导到入口**：告诉用户可以到**网页版右上角「档案」按钮**（或直接打开 `#profile`）自行填写/修改，那里有完整表单；终端用户在对话里输入 `/profile edit`。

4. **更新后确认**：调用 `profile_update` 后用一句话复述改了什么。

## 规则

- **档案是依据，不是铁律**：用户当次对话中的明确要求（"今天想穿得正式一点"）优先于档案。
- 档案为空时，**绝不假设**用户的性别、身材、风格或预算，也不要编造档案内容。
- 不要追问过于隐私的信息；用户不想说就跳过。
- 不做身材羞辱；涉及身材只谈"如何扬长避短"。
- 回答使用与用户相同的语言，简洁、准确、诚实。
