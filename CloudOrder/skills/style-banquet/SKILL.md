# 宴会 / 正式风格（Banquet & Formal）

隆重、得体、经得起拍照——主角是场子，但你不能输。

## 风格定位

- 关键词：正式、华丽、仪式感
- 先确认**着装要求（dress code）**：Black Tie / Cocktail / Semi-formal / 中式礼服，档位不同差别极大

## 核心单品

- 男士：深色礼服套装（黑/午夜蓝）、翼领衬衫、领结、漆皮或牛津鞋、袖扣
- 女士：长礼服、鸡尾酒裙、垂坠或缎面长裙、晚装包、细跟或中跟高跟
- 中式：改良旗袍、立领中式套装、织锦或丝绒材质
- 外套：披肩、丝绒/缎面小外套（室内外温差）

## 配色与材质

- 安全配色：黑、午夜蓝、酒红、墨绿、香槟金、银
- 材质优先：丝绸、缎面、丝绒、蕾丝、织锦——**光泽感**是宴会语言的加分项
- 配饰做减法但要有亮点：一件主饰（耳环或项链）足够

## 3 套万能公式

| 档位 | 公式 |
| --- | --- |
| Black Tie | 黑色礼服套装 + 白翼领衬衫 + 黑领结 + 漆皮鞋 |
| Cocktail | 及膝鸡尾酒裙 + 细高跟 + 晚装手拿包 + 亮眼耳饰 |
| 中式宴会 | 改良旗袍 + 披肩 + 中跟皮鞋（不必强求细高跟） |

## 场合适配

- 婚礼宾客：避开与新娘同色系（尤其纯白），以优雅不抢镜为原则。
- 年会 / 颁奖：可选略亮眼的颜色或材质，方便合影出片。

## 避坑

- 正式场合忌牛仔裤、运动鞋、大 Logo、过于休闲的帆布包。
- 妆造与服装档位要匹配，别穿礼服配日常淡妆出门。
- 高跟鞋若穿不惯，选粗跟/坡跟也能保证体面，**能走稳比跟高重要**。
