# 街头潮流风格（Streetwear）

有态度、有话题，靠版型和层次说话。

## 风格定位

- 关键词：潮流、宽松、层次、态度、话题单品
- 核心是**版型对比**和**叠穿层次**，不是堆 logo

## 核心单品

- 上装：OVERSIZE 卫衣、图案 T、工装衬衫、冲锋衣、MA-1 飞行夹克
- 下装：工装裤、宽松牛仔裤、运动束脚裤、降落伞裤
- 鞋：高帮 AJ/空军一号、厚底老爹鞋、板鞋
- 配饰：棒球帽、冷帽、腰包、墨镜、粗链、堆袜

## 配色与材质

- 安全配色：黑 + 白 + 灰、大地色系（卡其/军绿/棕）、撞色（橙配蓝）
- 材质：水洗牛仔、重磅棉、尼龙、抓绒——可混搭，但要有质感差异
- 层次公式：内薄外厚，露出下摆/领口形成"层次线"

## 3 套万能公式

| 风格 | 公式 |
| --- | --- |
| 高街 OVERSIZE | 宽大印花卫衣 + 工装裤 + 高帮球鞋 + 冷帽 |
| 机能风 | 冲锋衣 + 束脚裤 + 老爹鞋 + 腰包 |
| 复古滑板 | 图案 T + 水洗牛仔 + 板鞋 + 堆袜 |

## 场合适配

- 出片 / 逛街 / 音乐节：可大胆用撞色和话题单品。
- 上班等正式场合：街头风点到为止，只留一件潮流单品。

## 避坑

- 全身 OVERSIZE 会显矮显胖，上宽下窄或上窄下宽二选一。
- Logo 堆砌是新手最容易翻车的地方，留一个焦点就够。
- 配饰别超过 3 件，否则显得杂乱。
