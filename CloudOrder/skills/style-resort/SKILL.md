# 度假 / 旅行风格（Resort & Travel）

上镜、轻便、好打包——行李箱里每一件都要能打。

## 风格定位

- 关键词：明亮、轻盈、上镜、易打理
- 先分场景：**海边/海岛**、**城市 City Walk**、**户外露营**

## 核心单品

- 上装：亚麻衬衫、吊带/真丝上衣、速干 T、薄针织
- 下装：亚麻长裤、印花长裙、工装短裤、速干短裤、牛仔短裤
- 鞋：草编凉鞋、帆布鞋、舒适小白鞋、溯溪/徒步鞋（户外）
- 配饰：草帽、墨镜、丝巾、帆布/藤编包、防晒外套、大容量托特包

## 配色与材质

- 海边：白 + 蓝 + 沙色、明黄/橘 + 白（上镜）
- 城市：大地色 + 白，或一身同色系拉长身形
- 户外：大地色系（卡其/军绿/棕），避免纯白易脏
- 材质：亚麻、棉、真丝、速干面料；**透气 + 抗皱**是旅行刚需

## 3 套万能公式

| 场景 | 公式 |
| --- | --- |
| 海岛度假 | 亚麻衬衫 + 亚麻长裤 + 草编凉鞋 + 草帽 |
| 城市 City Walk | 素 T + 宽松牛仔 + 小白鞋 + 帆布托特包 |
| 户外露营 | 速干 T + 工装短裤 + 徒步鞋 + 防风外套 |

## 场合适配

- 拍照优先考虑"大面积纯色 + 一个亮点"的搭配，比花纹更出片。
- 用同一色系打包几套，配件互穿，能显著减少行李。

## 避坑

- 别带一堆"只适合拍照"的单品，走一天路才是真实使用场景。
- 亚麻易皱、纯棉不速干，按场景选面料，别搞反。
- 海岛紫外线强，防晒外套 + 帽子比防晒霜更实在。
