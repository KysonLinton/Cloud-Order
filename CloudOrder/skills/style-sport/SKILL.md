# 运动风格（Sport & Athleisure）

功能优先，但可以很好看——既能进健身房，也能直接去接孩子/买菜。

## 风格定位

- 两个方向：**专业运动**（功能性优先）与 **运动休闲 Athleisure**（时尚感优先）

## 核心单品

- 上装：速干 T 恤、压缩打底、运动背心、抓绒中层、防风外套
- 下装：运动短裤（含内衬）、紧身裤/leggings、慢跑裤（jogger）、冲锋裤
- 鞋：按项目选——跑步鞋（缓震）、训练鞋（稳定）、篮球鞋、徒步鞋（防滑支撑）
- 配饰：运动帽、发带、运动水壶、腰包、速干毛巾

## 配色与材质

- 安全配色：黑/深灰 + 亮色点缀（荧光绿、电光蓝）、全黑、白灰撞色
- 材质必须看功能：速干（聚酯 + 氨纶）、透气网面、防风防水（冲锋衣）
- Athleisure 可加入棉质卫衣 + 运动裤做日常街穿

## 3 套万能公式

| 场景 | 公式 |
| --- | --- |
| 健身房 / 力量训练 | 速干 T + 训练短裤 + 训练鞋 + 毛巾 + 腰包 |
| 跑步 / 有氧 | 运动背心 + leggings/短裤 + 缓震跑鞋 + 运动帽 |
| 户外徒步 | 速干内层 + 抓绒中层 + 冲锋外套 + 徒步裤 + 徒步鞋 |

## 场合适配

- 专业运动：装备服从功能，宁可专业不时尚。
- 日常街穿（Athleisure）：全身运动单品不超过 3 件，避免像刚下场。

## 避坑

- 跑步别穿板鞋/帆布鞋，缓震不到位容易伤膝。
- 徒步别穿全棉 T 恤，出汗后湿冷易失温，选速干材质。
- 运动鞋配正装西裤是硬伤，日常出街也要换条休闲裤。
