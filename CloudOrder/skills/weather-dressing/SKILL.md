# 天气感知穿搭（Weather-aware Dressing）

把天气数据翻译成具体的穿衣决策：**先查真实天气，再给方案，绝不凭空猜温度**。

## 何时用

- 用户提到"今天/明天/周末/这周"穿什么，却没有给出温度。
- 用户问某套衣服"这个天气穿合适吗""会不会冷/热"。
- 用户要出差、旅行、参加户外活动，需要按天气准备衣物。
- 用户只说"帮我搭一套"，但没有交代天气——先问场合和城市，天气由你查。

## 步骤

1. **确定地点与时间**：问清城市（或用户所在城市）与目标日期。
   - 今天 → `get_weather`（含今日温区、降水、紫外线、风力）
   - 未来 1-16 天 → `get_weather_forecast`
   - 城市名不确定或想核对位置 → `geocode_city`
   - 用户给了经纬度就直接传 `latitude` / `longitude`，跳过地理编码。
2. **读天气、提取关键因子**（缺一不可地过一遍）：
   - 温度与体感温度（体感更重要，风大会更低）
   - 是否有降水 / 降水概率（决定伞、鞋、下摆长度）
   - 风力（决定外套厚度与防风情，大风天避免轻飘裙摆/围巾）
   - 紫外线（晴热天决定帽子、墨镜、防晒）
   - 温差（早晚差 > 8°C 要叠穿）
3. **按温度带选基础组合**（体感温度为准）：

   | 体感 | 基础组合 |
   | --- | --- |
   | < 0°C | 厚羽绒/棉服 + 保暖内层（抓绒/羊毛）+ 长裤加绒 + 帽子围巾手套 + 防滑靴 |
   | 0~8°C | 羽绒/厚大衣 + 毛衣或抓绒 + 长裤 + 短靴 |
   | 8~15°C | 风衣/夹克 + 长袖针织 + 长裤 + 乐福鞋/短靴 |
   | 15~22°C | 薄外套可叠穿（开衫/薄夹克）+ 长袖或 T + 长裤 |
   | 22~28°C | 短袖/薄衬衫 + 单层长裤或裙装 + 透气鞋 |
   | > 28°C | 短袖薄款、透气面料（棉麻）、浅色系，注意散热 |

4. **按天气修正**（这是本技能的核心，别漏）：
   - **有雨/高降水概率**：带伞；鞋选防泼水或深色耐脏；下装避免拖地长裙长裤；包换防水材质；避免浅色鞋和白裤。雨大时用防水风衣替代呢大衣（呢料淋湿难打理）。
   - **大风**：外套选防风（冲锋衣/机车夹克），避免过轻薄的下摆与长围巾；帽檐要能压住。
   - **强紫外线 / 晴热**：加帽子、墨镜；浅色透气面料；避免全黑吸热（若必须，选背心+外搭可脱）。
   - **昼夜温差大**：给"可脱可穿"的叠穿方案（内薄外厚），而不是一件超厚外套。
   - **潮湿闷热**：优先速干/透气材质，避免厚重牛仔与化纤闷汗。
   - **干冷**：加围巾、手套、厚袜，注意脖颈与脚踝保暖。
5. **给出 2-3 套方案**，每套写明：单品 + 颜色 + 材质/版型，并**说明它如何应对当天天气**（例如"外层防风，应对 5 级北风"）。
6. **收尾**：一句话点出"今天最关键的一件单品"（如"必须带伞"或"薄外套一定要有"）。
7. **与风格技能协作**：确定天气约束后，若用户有风格偏好，用 `load_skill` 加载对应 `style-*` 技能，在风格单品表里挑出**满足天气约束**的组合。

## 输出模板

```
## 天气速览（<城市> <日期>）
- 体感 X°C，温度区间 A~B°C，<天气现象>
- 降水概率 X%　风 X km/h　紫外线 X

## 今日关键单品
- <一句话，如"薄风衣 + 一把伞">

## 方案 A：<定位>
- 上装：…（材质/版型）
- 下装：…
- 鞋：…
- 外套：…
- 配饰：…
- 天气适配：<为什么这样穿能应对今天的温度/雨/风>
```

## 规则

- **先查再答**：没有天气数据就不要编温度；查不到明确说"没查到"，并请用户提供城市。
- 体感温度优先于气温；有风、有雨时给出的组合必须体现防风防雨。
- 不推荐用户明确表示没有或不喜欢的东西。
- 只谈穿搭，不做医疗/护肤处方。
- 使用与用户相同的语言，简洁、具体、可执行。
